# モデル操作ウィンドウ 設計

日付: 2026-08-08
対象ブランチ: feat/self-model-placement-remaining

## 背景

配置モデル機能の操作UIは現在 `ModItemWindow` の情報ペイン内にインラインの Transform 行として実装されているが、使いにくい。独立した「モデル操作ウィンドウ」に集約し、あわせて回転ギズモの座標系バグ修正・アタッチポイント・複数プリセット対応を行う。

## 要件

- 編集モードが「モデル」のときのみ自動表示される独立ウィンドウ
- 操作対象モデルの選択、表示/非表示、削除
- 移動/回転/拡縮の排他トグル(既存 `SelfModelPlacer.dragType` に接続)
- 位置/回転/拡縮の X/Y/Z 数値編集。ラベルを左右ドラッグで数値変更(1px あたり 位置 0.01m / 回転 1° / 拡縮 0.01、Shift 押下で 0.1 倍)
- アタッチポイント: 選択メイドのボーン(スタジオ準拠の定番リスト+「なし」)への取り付け。切替時はローカル位置リセット
- プリセット: 名前付きファイルで複数作成/保存/読込/削除
- 回転は UI・保存ともローカルオイラー角に統一し、X/Y 回転時に全成分が変動する問題を修正

## 1. ウィンドウ構成(新規 `ModelOperationWindow`)

`MotionWindow` 等と同じ `IWindow` 実装の独立ウィンドウを新設し、`WindowManager` に登録する。`ModItemWindow` の `_contentMode == ContentMode.モデル` のときのみ表示し、他モードでは非表示。`ModItemWindow` 情報ペインの既存 Transform 行(`MODEL_TRANSFORM_ROW_COUNT` 関連)は撤去する。

レイアウト(上から):

1. **モデル選択**: 配置済みモデル(自前配置分)のスクロールリスト。行に 表示/非表示トグル・モデル名・削除ボタン。行クリックで操作対象を選択
2. **操作種別**: 移動/回転/拡縮 の排他トグル
3. **Transform 編集**: 位置/回転/拡縮 各行に X/Y/Z のドラッグ可能ラベル+数値フィールド+リセットボタン
4. **アタッチ**: アタッチ先ボーンのコンボボックス(対象メイドは選択中メイド固定。メイド選択 UI はスコープ外)
5. **プリセット**: 名前入力+保存ボタン、既存プリセット一覧コンボボックス+読込/削除ボタン

## 2. ドラッグ可能ラベル(GUIView 拡張)

`GUIView` に `DrawDragLabel`(仮称)を追加する。

- ラベル矩形上の MouseDown でドラッグ開始、MouseDrag の横方向 delta × 感度を `onChanged(delta)` に渡す。MouseUp で終了
- 感度: 位置 0.01m/px、回転 1°/px、拡縮 0.01/px。Shift 押下中は 0.1 倍
- ドラッグ中はウィンドウ自体のドラッグ移動を抑止する(ドラッグ中ラベル ID をウィンドウ側 state で管理)
- 数値フィールドは既存 `DrawFloatField` / `FloatFieldCache` を流用

## 3. 回転バグ修正(ローカルオイラー統一)

- UI 側: 操作対象モデルに `TransformCache`(MTEUtils 既存)を使い、`localEulerAngles` を保持・編集する。外部(ギズモ)による回転変更はクォータニオン比較で検出し、変わっていないときはキャッシュ済みオイラー角を維持してオイラー角の飛びを抑える
- ギズモ側: `GizmoRender` の回転操作がワールド軸で掛かっているのが原因と推定。実機(devbridge)で `eRotate` 操作時の挙動を確認し、ローカル軸回転になるよう補正する(必要なら回転結果を `localRotation` に再適用する後処理を入れる)
- プリセット保存/復元も `localPosition` / `localEulerAngles` / `localScale` に統一する(現状は `position` / `eulerAngles`)

## 4. アタッチポイント

- 対象: 選択中メイド(`ModItemManager.currentMaid`)のボーン。スタジオ準拠の定番リスト(頭/首/胸/骨盤/左右の肩・肘・手・腿・膝・足 など約 20 箇所)+「なし(ワールド)」。複数メイドからの選択 UI は今回スコープ外
- 実装: ラッパー GO の親をボーン Transform に付け替える(`SetParent(bone, false)` でローカル Transform リセット)。「なし」選択で `ParentObjectName` 配下に戻す
- ボーン取得は `maid.body0.GetBone(name)` 系 API を使用(実際のボーン名は実機で裏取りする)
- プリセットにはアタッチ先(メイドスロット番号+ボーン名)とローカル Transform を保存する。復元時に該当メイドがいない場合はワールド配置にフォールバックする

## 5. 複数プリセット

- 保存先: プラグイン設定ディレクトリ配下の `ModelPresets/` フォルダに `<名前>.xml`
- `ModelPlacementPreset` / `ModelPlacementPresetItem` を拡張してアタッチ情報(メイドスロット番号・ボーン名)を追加
- UI: 名前入力+保存(同名は確認なしで上書き)、コンボボックスで一覧選択 → 読込 / 削除
- 既存の単一ファイル `PluginUtils.ModelPresetPath` は廃止する。開発中機能のため移行処理は入れない

## 実装順

1. 回転バグ修正(ローカルオイラー統一+ギズモ補正)
2. `ModelOperationWindow` 骨格+モデル選択/操作種別/Transform 編集(`DrawDragLabel` 含む)+ ModItemWindow 側の旧 UI 撤去
3. アタッチポイント
4. 複数プリセット

## テスト

自動テスト基盤がないため、各段階で実機(devbridge)により以下を確認する:

- X/Y/Z 各軸の回転ギズモ操作で該当軸の数値のみが変化すること
- ドラッグラベル・数値入力・ギズモの 3 経路の編集が相互に矛盾なく反映されること
- アタッチ切替(ボーン→別ボーン→なし)で位置がボーン直上にリセットされること
- プリセットの保存→読込でアタッチ状態含め復元されること

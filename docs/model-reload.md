# モデルの再読み込み

更新済みの `.model` / `.mate` / `.tex` / `.menu` を元のModフォルダーへ上書きした後、プラグインのボタンから読み直せます。ファイルのコピーやBlenderからの出力はこの機能には含みません。

## 着用中の衣装

メイド編集モードで対象のメイドと着用中のアイテムを選び、ヘッダー3行目の **選択衣装を再読込** を押します。未着用のアイテム、読み込み中、非表示のメイドでは押せません。アイテム一覧の通常クリックには従来どおり装備の適用動作があります。

通常装備・一時装備のmenu名とRID、スケール設定を書き換えず、現在有効な装備を再処理します。選択アイテムにカラーセットの関連付けがある場合は、その部位の現在のカラー設定も再処理します。新フェイスの左右のアイハイライトは既存の適用処理と同様に両方を対象にします。

結果はボタン横とログに表示します。30秒で待機を打ち切った場合は完了扱いにしません。待機の打ち切りはゲーム本体の読み込みの強制中断ではありません。読み込み中の再実行と通常のmenu適用を防ぎます。

## 自前配置したモデル

モデル操作ウィンドウで対象を選択し、操作タブの **選択モデルを再読込** を押します。ModItemExplorer自身がmenuから配置したモデルが対象です。Prefab・背景アセット・マイルームオブジェクト・他プラグイン管理のモデルは対象外です。

新しいモデルを別に読み込み、読み込みに成功してから中身を交換します。読み込み段階で失敗した場合は元のモデルを保持します。位置・回転・拡縮・表示・レイヤー・メイドへのアタッチ・選択・操作履歴が参照する外側のオブジェクトは維持します。同じモデルを複数配置していても対象の1個だけを読み直します。

材質はファイルの内容から作り直します。実行中にRendererや材質へ直接加えた変更、および旧モデル内部のボーンやRendererへの外部参照は引き継ぎません。再読み込み自体はUndoに追加せず、ファイル内容の巻き戻しもしません。

## ファイルの認識と制限

- 既存ファイルの上書き更新はいつでも反映します。
- 同じフォルダーへ**新しく追加した**mateやtexは、そのフォルダーを再読み込みする初回だけ検索対象へ入ります。同一セッションで2回目以降に追加したファイルはゲームを再起動するまで見つかりません（ゲーム本体のファイルシステムが登録済みフォルダーを再走査しないため）。
- Mod配下に同名menuが複数ある場合は、検索順を変えないよう処理を中止します。
- 更新するのはファイルの存在確認キャッシュです。他のプラグインが持つ独自キャッシュの強制破棄は行いません。
- 衣装の読み込みはゲーム本体に委ねます。破損ファイルやmenu命令の変更による副作用を完全に巻き戻す機能ではありません。
- 「衣装の再読み込み処理が完了」はゲーム本体の処理終了と対象menuの一致の確認です。メッシュ・テクスチャの内容や画面表示の一致を自動検証したという意味ではありません。
